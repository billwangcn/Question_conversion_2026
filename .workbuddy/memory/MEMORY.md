# E学院试题转换23-26 项目笔记

## 项目目标
在旧版（2023，文件名 _2023）与新版（2026，文件名 _2026）试题格式之间互转，导入导出均为 Word .doc。

## 命名规则（用户 2026-10-26 明确确认）
- 输出文件名后缀跟随**源文件**版本，而不是目标格式：
  旧版题库转换后仍叫 `xxx_2023.doc`（内容已是新版格式），新版题库转换后仍叫 `xxx_2026.doc`（内容已是旧版格式）。
- 即「后缀 = 题库年份/来源」，格式由用户选择的转换方向决定。

## 格式约定
- 旧版：`N、题干` + `A./B.` 选项 + 答案（单选常用「【答案】D」，多选「正确答案：ABCD」）+「【难度】一般」；判断题答案内联在题干末尾「（正确）/（错误）」；全部混排无分节。
- 新版：按【单选题开始/结束】【多选题开始/结束】【判断题开始/结束】分节；答案一律「正确答案：X」；引号等用 HTML 实体（&ldquo; &rdquo; &lsquo; &rsquo; &mdash;）；题号各节连续（不重新从 1 编）。
- 互转规则：转新版按题型分组重排（可关）；转旧版去分节；实体与普通引号双向转换。

## 技术要点（务必记住）
- 本机（Python 3.13）PyQt5 5.15 QApplication 必崩，必须用 PyQt6；程序已做 PyQt6 优先/PyQt5 兼容双绑定。
- 依赖在项目 `.venv`（PyQt6、python-docx、pywin32），启动用 `启动.bat`。
- Word COM：`DispatchEx("Word.Application")`，需 `Documents.Add()` 保活防自动退出；读取 `doc.Content.Text`（\r\x07 需规整为 \n）；另存 .doc 用 `SaveAs2(path, 0)`；WPS 兜底 `KWPS.Application`。
- 解析器要点：题号连续性校验防误判；选项字母需按 A、B、C 递增；「结束」分节后要清空 section 状态。
