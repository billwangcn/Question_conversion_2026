# 2026-10-26

## E学院试题格式互转工具（新完成）
- 交付 `E学院试题格式互转.py`（约 1270 行，单文件）+ `启动.bat`。
- 功能：旧版（_2023，无分节，答案为「正确答案：/【答案】」混用）与新版权试题（_2026，带【单选题/多选题/判断题开始/结束】分节，答案统一「正确答案：」，引号用 HTML 实体 &ldquo; 等）互转；导入导出均为真正的 Word .doc（python-docx 生成 docx → Word COM 另存为 .doc，WPS 兜底）。
- 界面：PyQt，拖拽批量添加、自动识别方向、预览+题量统计+可疑题提示、后台线程转换、设置记忆（QSettings）。
- 关键经验：
  - 本机 Python 3.13 上 PyQt5 5.15 的 QApplication 会直接崩溃（exit 127），PyQt6 6.11 正常 → 程序做成 PyQt6 优先、兼容 PyQt5 的双绑定。
  - Word COM 自动化时进程会在关闭最后一个文档后自行退出 → WordBridge 里用 `Documents.Add()` 保活文档 + 存活探测 + 失败自动重建重试。
  - 沙箱内 Qt 无法建窗口，用 `QT_QPA_PLATFORM=offscreen` + 伪造 `QApplication.exec_` 截图可离线验证界面（中文字体显示为方块属正常）。
- 测试：`测试数据/自测.py`（文本互转）、`--export`（DOC 导出）、`ui_shot.py`/`e2e_ui.py`（界面截图）；往返转换 新→旧→新 内容一致。
- 依赖装在项目内 `.venv`（PyQt6、python-docx、pywin32），未污染全局环境。
